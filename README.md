# HeyX on GitHub

This repository contains the public GitHub organization profile for [HeyX](https://heyx.app), software for the residential energy transition.

- [`profile/README.md`](profile/README.md) is displayed on the organization homepage.
- [`profile/hero.svg`](profile/hero.svg) is the profile banner, based on the logo and teal visual style of heyx.app.

Update the profile files here to keep the organization page aligned with [heyx.app](https://heyx.app).
